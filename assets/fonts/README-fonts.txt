Fonts used by the Journal
=========================

CarroisGothicSC-Regular.ttf
  Titles and buttons. Copyright (c) 2011 by Ralph du Carrois, with
  Reserved Font Name 'Carrois'. SIL Open Font License 1.1.

FiraSans-Regular.ttf, FiraSans-Bold.ttf, FiraSans-Italic.ttf
  The step text: regular, bold for zones and italic for other places.
  Copyright (c) 2012-2015, The Mozilla Foundation and Telefonica S.A.
  SIL Open Font License 1.1. The full text is in OFL-FiraSans.txt.
  The files are unmodified copies from the Google Fonts repository.

Hexenkotel.ttf
  The name of the zone banner (fantasy letters) when KensingtonParlor.ttf
  is missing; it was the font of the banner before. By Tup Wanders
  (https://wanders.work), version 1.00, November 25, 2024; the font says
  "Free font. DO NOT SELL" and its license is the SIL Open Font License 1.1,
  with Reserved Font Name "Hexenkötel" (the text is in OFL-Hexenkotel.txt).
  The file is the one the user provided, unmodified, with a shorter name.

UncialAntiqua-Regular.ttf
  The name of the zone banner when KensingtonParlor.ttf and Hexenkotel.ttf
  are missing (medieval
  fantasy letters). Copyright (c) 2011
  by Brian J. Bonislawsky DBA Astigmatic (AOETI), with Reserved Font Name
  "Uncial Antiqua". SIL Open Font License 1.1, the text is in
  OFL-UncialAntiqua.txt. It is the Latin set of the font as the npm package
  @fontsource/uncial-antiqua 5.3.0 gives it, converted from WOFF to TTF.

KensingtonParlor.ttf
  The titles of the alerts (New Quest!, Quest Completed...) and the name of
  the zone banner. "Kensington
  Parlor" Regular, version 1.000 (2026). The file has no copyright or license
  text, so check its license before sharing the addon. It is the one the user
  provided, unmodified, with a shorter name. (The file VisualFantasyDemo.otf,
  used before, is not used any more and can be deleted.)

calibri.ttf
  Not used by the Journal code at the moment.
